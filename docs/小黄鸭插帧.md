# 用「小黄鸭」(Lossless Scaling) 给王国之泪 / 旷野之息插帧

作者：**DeliKitch**

## 原理

小黄鸭对游戏窗口做帧生成：游戏按 60（或 120）FPS 渲染 → 输出 120/180 FPS 显示，画面更顺滑，不增加游戏 CPU 负担。

## 王国之泪（原生版）

| 设置位置 | 值 |
|---|---|
| `totk.ini` → `fps_limit` | **60**（给插帧稳定基准）|
| 游戏内 F1 → 帧生成 | **关**（若菜单里有 dlssg 选项）|
| `vk_present` | `mailbox`（垂直同步开，帧时间更稳）|
| 分辨率 | 2560x1440 |
| 小黄鸭 Frame Generation | LSFG 2x（60→120）或 3x（60→180）|
| 小黄鸭 Capture API | Windows Graphics Capture |

> 追求最高帧：游戏内锁 120，小黄鸭再 1.5x/2x；但 2K 下 120 帧 + 插帧会让显卡接近满载，按需选择。

## 旷野之息（Cemu）

| 设置位置 | 值 |
|---|---|
| 图形包 FPS++ | 60（不要选 120，交给小黄鸭）|
| Cemu 垂直同步 | 关（配合 G-Sync）|
| 小黄鸭 Frame Generation | LSFG 2x/3x |
| 小黄鸭 Capture API | Windows Graphics Capture |

## 常见问题

- **画面抖动/重影**：降低插帧倍数；开小黄鸭的同步模式；游戏内先关垂直同步试试。
- **掉帧**：小黄鸭本身吃显卡，显卡满载时反而掉帧——降低游戏画质（DLSS 平衡/性能）。
- **菜单闪烁**：正常，小黄鸭对 UI 插帧可能瑕疵，可关闭光标相关选项。
- **延迟增加**：插帧约增加 1 帧延迟，动作游戏建议 2x，不要 4x。
